# 🇮🇳 Indian Crime Data Analysis | Power BI

## 📊 Project Overview

An interactive Power BI dashboard developed to analyse Indian crime data and uncover meaningful trends, patterns and regional insights.

The project focuses on transforming raw crime data into an intuitive visual analysis that can support data-driven understanding and decision-making.

## 🎯 Objectives

- Analyse crime trends across different years and regions
- Identify patterns in crime distribution
- Compare crime statistics across states/categories
- Develop interactive and meaningful Power BI visualisations
- Convert raw data into actionable insights

## 🛠️ Tools & Technologies

- Data Visualisation
- Microsoft Excel / CSV
